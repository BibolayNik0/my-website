# Волна — музыкальная соцсеть

Музыкальное приложение в духе SoundCloud / Яндекс Музыки с профилями как в Instagram.
Работает без сервера и сборки: просто откройте `index.html` или включите GitHub Pages.

## Что умеет

- **Профили**: аватар, ник, имя, описание, счётчики треков / подписчиков / подписок.
- **Страница друга**: вкладки «Треки» и «Нравится». Во второй видно, какие песни лайкнул друг,
  сколько у вас общих лайков, и есть кнопка «Слушать все».
- **Подписки**: подписка/отписка, списки подписчиков и подписок, «подписан(а) на вас»,
  общие подписчики, рекомендации, кого добавить.
- **Лента**: новые треки и лайки людей, на которых вы подписаны, кружки-«истории» сверху.
- **Плеер**: очередь, пауза, перемотка по волне трека, громкость, управление с клавиатуры (пробел)
  и с экрана блокировки (Media Session).
- **Лайки и комментарии**, список тех, кто лайкнул трек.
- **Обзор**: поиск людей и треков, фильтр по жанрам, «Популярное» и «Новое».
- **Создание трека**: можно загрузить свой аудиофайл с обложкой или сгенерировать бит в выбранном жанре.
- **Приватность**: можно скрыть свои лайки от других.
- Тёмная тема, адаптивная вёрстка (на телефоне — нижнее меню как в Instagram).

## Как это устроено

- `js/synth.js` — синтезатор на Web Audio API. Демо-треки не хранятся файлами,
  а собираются из «зерна» и жанра (Lo-Fi, House, Synthwave, Trap, Ambient, Pop).
- `js/store.js` — данные (пользователи, треки, лайки, подписки, комментарии) в `localStorage`,
  загруженные аудиофайлы — в IndexedDB.
- `js/app.js` — интерфейс, роутинг (`#/u/<ник>`, `#/u/<ник>/likes`, `#/t/<id>`, `#/explore`, …) и плеер.

Для входа есть шесть демо-аккаунтов (пароль у всех `demo`), можно зарегистрировать свой.

## Ограничение

Всё хранится в браузере, поэтому «друзья» — это аккаунты на этом же устройстве.
Чтобы люди видели друг друга с разных устройств, нужен бэкенд (например, Supabase или Firebase):
слой `Store` для этого специально вынесен в отдельный файл.
