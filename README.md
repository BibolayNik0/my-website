# Toyota Caldina T240 (2003) — 3D-разборка

Интерактивная 3D-модель синей Toyota Caldina 2003 года, которую можно разобрать «до винтика».

- **453 детали**, каждая — отдельный объект с названием и описанием: кузовные панели, стёкла, фары,
  двигатель 1AZ-FSE (поршни, шатуны, коленвал, распредвалы, свечи, катушки, болты ГБЦ…),
  АКПП и приводы, подвеска, тормоза, колёса (вплоть до гаек, шпилек и вентилей), выхлоп, салон.
- Ползунок разборки в три стадии: кузов и навесное → агрегаты и системы → детали и крепёж.
- Наведение — подсказка с названием, клик — подсветка и карточка детали.
- Дерево деталей по системам с поиском, скрытие систем и отдельных деталей, режим «только эта».
- Режим «прозрачный кузов», чтобы видеть начинку собранной машины, и режим «без цвета» (матовая белая «глина»).

Модель процедурная (построена в коде, размеры близки к реальным), это не заводская документация.
Кузов — гладкая параметрическая поверхность (`js/bodysurf.js`): боковины с завалом, скруглённые в плане
нос и корма, выпуклые капот и крыша. Панели вырезаются из неё по контурам, поэтому стыки совпадают.

## Запуск

Сборка не нужна — это статический сайт на [three.js](https://threejs.org/) и delaunator (подключаются с CDN).

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

Для GitHub Pages: Settings → Pages → Deploy from a branch → корень ветки.

## Структура

- `index.html`, `css/style.css` — страница и интерфейс
- `js/main.js` — сцена, камера, выбор деталей, UI
- `js/car.js` — агрегаты, ходовая, салон
- `js/carbody.js` — кузовные панели, стёкла, светотехника
- `js/bodysurf.js` — поверхность кузова и построение листовых деталей (триангуляция Делоне)
- `js/geo.js` — геометрические помощники (панели кузова, болты, пружины, ремни)
- `js/registry.js` — реестр деталей и логика разлёта
- `js/desc.js` — описания деталей
