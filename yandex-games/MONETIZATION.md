# Настройка монетизации в консоли Яндекс Игр

Все 100 игр используют одинаковые ID товаров и лидерборда. Для каждой игры в консоли разработчика:

## 1. Внутриигровые покупки

Включите покупки (запрос партнёрской команде после публикации черновика) и создайте товары:

| ID | Тип в коде | Рекомендуемая цена | Что выдаёт |
|---|---|---|---|
| `gems_small` | расходуемый | 29 ян | 80 💎 |
| `gems_medium` | расходуемый | 79 ян | 250 💎 (метка «ХИТ») |
| `gems_large` | расходуемый | 199 ян | 700 💎 (метка «ВЫГОДНО») |
| `gems_huge` | расходуемый | 499 ян | 2000 💎 (метка «ЛУЧШЕЕ») |
| `chest_bundle` | расходуемый | 249 ян | 10 королевских сундуков, первый — легендарный |
| `starter_pack` | постоянный | 49 ян | 300 💎 + 5000 монет + эпический предмет, один раз |
| `no_ads` | постоянный | 99 ян | отключает межстраничную рекламу |
| `vip` | постоянный | 199 ян | x2 монеты, +20 💎 в день, бесплатный сундук каждые 2 ч |
| `season_pass` | постоянный | 149 ян | премиум-дорожка боевого пропуска |

Цены в игре берутся из `getCatalog()`, поэтому их можно менять в консоли без пересборки. Запасные цены (если каталог недоступен) — в `engine/sdk.js` → `PRODUCTS`.

**Обработка платежей** (`engine/core.js`):
- Расходуемые товары выдаются и сразу списываются через `consumePurchase`.
- Постоянные товары не списываются и восстанавливаются при каждом запуске через `getPurchases()`.
- Необработанные платежи (вкладку закрыли во время оплаты) выдаются при следующем запуске — это требование модерации.

## 2. Лидерборд

Создайте лидерборд с техническим названием `score` (по убыванию). Рекорд отправляется в конце раунда; для кликеров — сумма заработанного при выходе в меню.

## 3. Реклама

Ничего настраивать не нужно: используются `showFullscreenAdv` и `showRewardedVideo`. Правила показа зашиты в движке:
- межстраничная — только между раундами, не после первого раунда и не чаще раза в ~65 с;
- на время рекламы игра и звук ставятся на паузу, вызывается `GameplayAPI.stop/start`;
- у купивших `no_ads` межстраничная реклама не показывается, а rewarded остаётся по желанию игрока.

## 4. Публикация

```bash
npm run build      # dist/zips/NNN-slug.zip — 100 архивов, index.html в корне
npm run check      # дымовой тест всех игр в headless Chromium
```

```bash
npm run promo      # dist/promo/NNN-slug/: icon-512.png, cover-800x470-{ru,en}.png, screenshot-{port,land}-{1..3}.jpg, listing.txt
```

Загрузите zip в черновик игры, а из папки `dist/promo/NNN-slug/` — иконку, обложку и скриншоты. Название, описание, «как играть» и категорию скопируйте из `listing.txt` (или из сводной таблицы `dist/promo/listings.csv`, открывается в Excel).

Языки: игра автоматически выбирает русский или английский по `environment.i18n.lang`; в консоли укажите оба языка и заполните название/описание из `catalog/games.js`.

## 5. Как менять баланс

- Цены улучшений, шансы сундуков, гарантии, награды пропуска и ежедневок — константы в начале `engine/core.js`.
- Параметры конкретной игры (скорость, размер поля, число ходов и т. д.) — поле `p` в `catalog/games.js`.
- Новая игра = одна строка `G(...)` в каталоге + `npm run build`.
