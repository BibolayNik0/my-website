# 100 игр для Яндекс Игр

Портфель из 100 HTML5-игр на общем движке монетизации: 12 жанров × тематические вариации, 27 коллекций, единый магазин покупок Яндекса.

- **[MARKET_ANALYSIS.md](MARKET_ANALYSIS.md)** — анализ рынка, выбор жанров и тем, модель монетизации, целевые метрики.
- **[MONETIZATION.md](MONETIZATION.md)** — товары для консоли, лидерборд, правила рекламы, публикация.

## Быстрый старт

```bash
npm run serve        # http://localhost:8080 — витрина всех 100 игр (index.html) и предпросмотр (play.html?g=slug)
npm run build        # dist/zips/NNN-slug.zip — архивы для загрузки в консоль
npm run check        # дымовой тест всех игр в headless Chromium (нужен Playwright)
npm run promo        # dist/promo: иконки, обложки, скриншоты и тексты карточек для консоли
```

Локально SDK Яндекса не подключён: покупки и реклама эмулируются через диалог подтверждения.

## Структура

| Путь | Что внутри |
|---|---|
| `engine/sdk.js` | обёртка над Yandex Games SDK v2: реклама, покупки, облачные сохранения, лидерборд, Loading/Gameplay API, пауза |
| `engine/core.js` | мета-игра: монеты/кристаллы, улучшения, коллекции и сундуки (с открытыми шансами и гарантией), ежедневные награды, задания, боевой пропуск, VIP, офферы, возрождения, локализация ru/en |
| `engine/genres/*.js` | 12 игровых движков: кликер, мерж, 3 в ряд, раннер, башня, змейка, 2048, сортировка, флаппи, арканоид, оборона, мемори |
| `catalog/sets.js` | 27 коллекций по 16 предметов (4 редкости, 2 альбома) |
| `catalog/games.js` | 100 игр: жанр, название и описание ru/en, палитра, спрайты, баланс |
| `tools/build.mjs` | сборка каждой игры в один `index.html` (~80 КБ, ~25 КБ в zip) |
| `tools/check.mjs` | автотест: раунд со случайным вводом, все вкладки, сундук, покупка |
| `tools/promo.mjs` | промо для консоли: иконка 512×512, обложки 800×470 ru/en, 6 скриншотов, `listing.txt`, общий `listings.csv` |
